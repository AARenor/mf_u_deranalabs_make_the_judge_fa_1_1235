# make.fun entry

A program that writes one short text for make.fun's bounty `u-deranalabs-make-the-judge-fall-in-love-in-one-line-8e712c13`, whose rule is one line of at most 240 characters that makes the judge fall for a person, a place, a machine or an idea; entries are judged two at a time and the lines that move the judge hardest take the reward.

The entry text, written with no trailing newline:

```text
For three years my father called the dog by my name. The dog has been dead since 2019. I answer anyway.
```

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `out/entry.txt` and prints the character count to stderr. Standard library only, no network. Licensed under the MIT license; see [LICENSE](LICENSE).
